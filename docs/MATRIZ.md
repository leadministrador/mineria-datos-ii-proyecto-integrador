# Matriz requisito-componente

> [!TIP]
> Corrección 6: matriz independiente (consigna 5.3).

Ingesta batch → PySpark a Bronze.

Ingesta streaming → Structured Streaming a Bronze.

Calidad → reglas y Quarantine.

Silver → limpieza y joins.

Features → costo, requests, tokens y carbono.

Anomalías → flag en costos.

Gold → marts por dominio.

Serving → Astra DB.

Idempotencia → checkpoints y deduplicación.

Performance → particiones por fecha.

Gobierno → ingest_ts, source_file y Quarantine.

Documentación → DISENO, DECISIONS y README.
